# BPS AI Lead Scraper 🚀

A high-performance lead generation tool built with FastAPI and React, designed to pull targeted business data from Google Maps.

## ✨ New Features
*   **Multi-City Aggregation**: Scrape multiple locations (comma-separated) in one go.
*   **Intelligent Location Tagging**: Each lead is tagged with its specific city.
*   **Terminology Refinement**: Simplified dashboard using "Location" and "Keyword".
*   **Unified Export**: One CSV file for all your findings.

## 🛠 Tech Stack
-   **Backend**: FastAPI
-   **Frontend**: React (Vite)
-   **Automation**: Playwright
-   **Data**: Pandas
